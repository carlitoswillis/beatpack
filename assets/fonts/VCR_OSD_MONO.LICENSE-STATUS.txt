VCR_OSD_MONO_1.001.ttf -- LICENSE UNRESOLVED
============================================

This font is redistributed in this public repository with NO license
anywhere: not in a file beside it, and not inside the font itself.

What the font's own `name` table actually contains (parsed directly from
public/VCR_OSD_MONO_1.001.ttf, not recalled):

    nameID  1  Family      : VCR OSD Mono
    nameID  2              : Regular
    nameID  3              : VCR OSD Mono:Version 1.001
    nameID  4              : VCR OSD Mono
    nameID  5  Version     : 1.001 March 31, 2015
    nameID  6              : VCROSDMono
    nameID  9  Designer    : MrManet
    nameID 18              : VCR OSD Mono

Absent, and these are the ones that would carry terms:

    nameID  0  Copyright              -- NOT PRESENT
    nameID 13  License Description    -- NOT PRESENT
    nameID 14  License Info URL       -- NOT PRESENT

Contrast public/bebas_neue/, which does this correctly: it ships OFL.txt
and OFL-FAQ.txt stating the SIL Open Font License 1.1.

ACTION REQUIRED (by a human, not automatable)
---------------------------------------------
The terms of this font have deliberately NOT been guessed. Someone must
either:

  (a) establish the actual license from the designer ("MrManet") or the
      source it was obtained from, and commit that text here; or
  (b) replace it with a font that ships explicit redistribution terms.

Until one of those happens, this repository is publishing a font whose
redistribution rights are unestablished. This file exists so that fact is
recorded rather than invisible.

The font is used by process/makeCover.js for cover-art text rendering, so
substituting it is a visual change, not a no-op.
