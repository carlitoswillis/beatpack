ACTION REQUIRED (by a human, not automatable)
---------------------------------------------
The terms of this font have deliberately NOT been guessed. Someone must
either:

  (a) establish the actual license from the designer ("MrManet") or the
      source it was obtained from, and commit that text here; or
  (b) replace it with a font that ships explicit redistribution terms.

Until one of those happens, this repository is publishing a font whose
redistribution rights are unestablished. This file exists so that fact is
recorded rather than invisible.

The font is used by process/makeCover.js for cover-art text rendering, so
substituting it is a visual change, not a no-op.
